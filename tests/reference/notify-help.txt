Send or inspect UPS notifications

Usage: nut notify [OPTIONS] [COMMAND]

Commands:
  test
          Send a test notification through the installed event hook

Options:
      --color <WHEN>
          Color output policy

          Possible values:
          - auto:   Color when writing to a terminal (default)
          - always: Color even when piped
          - never:  Never color

          [default: auto]

      --ascii
          Use ASCII symbols and bars

  -j, --json
          Emit machine-readable JSON where supported

  -v, --verbose
          Include additional diagnostic detail

  -c, --config <PATH>
          Read host settings from this file

  -h, --help
          Print help (see a summary with '-h')
