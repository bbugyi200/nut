List or restore a configuration backup

Usage: nut rollback [OPTIONS] [STAMP]

Arguments:
  [STAMP]
          Backup stamp to restore (defaults to the newest complete backup)

Options:
      --color <WHEN>
          Color output policy

          Possible values:
          - auto:   Color when writing to a terminal (default)
          - always: Color even when piped
          - never:  Never color

          [default: auto]

  -l, --list
          List available backups

      --ascii
          Use ASCII symbols and bars

  -n, --dry-run
          Show the restore plan without changing anything

  -j, --json
          Emit machine-readable JSON where supported

  -y, --yes
          Restore without an interactive prompt

  -v, --verbose
          Include additional diagnostic detail

  -c, --config <PATH>
          Read host settings from this file

  -h, --help
          Print help (see a summary with '-h')
